Structures an options strategy for a pension fund, where the client is bullish on the S&P500 index. 
We recommend a risk-reversal strategy. The code prices options with BSM, plots the payoff and Greeks of the RR, 
finds break-even price and animates risk sensitivities during decay.

Source code censored for university academic integrity purposes but can be provided upon request.
